# My dotfiles

Manage configurations using **GNU Stow**.

Run `make help` to see available commands.

## Environment

- **Window Manager**: i3
- **Launcher**: Rofi
- **Terminal**: Alacritty
- **Compositor**: Picom
- **Wallpaper Manager**: Variety
- **Bar**: Polybar
- **Input Method**: Fcitx5

## Utilities

- **Polkit Proxy**: LXPolkit
- **Hide Mouse**: Unclutter

## Recommended Fonts

- **Source Code Pro Regular**: Alacritty
- **Source Han Sans CN**: Rofi
- **Symbols Nerd Font Mono**: Rofi, Polybar
